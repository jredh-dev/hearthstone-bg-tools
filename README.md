## Data Structure

### Minion (`bg_minions.json`)

```json
{
  "id": "BG19_010",
  "dbfId": 70790,
  "name": "Sewer Rat",
  "type": "MINION",
  "set": "BATTLEGROUNDS",
  "cardClass": "HUNTER",
  "cost": 0,
  "attack": 3,
  "health": 2,
  "techLevel": 2,
  "race": "BEAST",
  "races": ["BEAST"],
  "text": "[x]<b>Deathrattle:</b> Summon a\n2/3 Turtle with <b>Taunt</b>.",
  "isBattlegroundsPoolMinion": true,
  "battlegroundsPremiumDbfId": 70801,
  "battlegroundsRelatedCard": 70791,
  "referencedTags": ["DEATHRATTLE", "TAUNT"]
}
```

**Key Fields**:
- `dbfId`: Unique identifier (use for references)
- `techLevel`: Tavern tier (1-7)
- `races`: Array of minion types
- `battlegroundsPremiumDbfId`: Link to golden version
- `referencedTags`: Mechanics (TAUNT, DIVINE_SHIELD, DEATHRATTLE, etc.)

### Hero (`bg_heroes.json`)

```json
{
  "id": "BG20_HERO_100",
  "dbfId": 70838,
  "name": "Rokara",
  "type": "HERO",
  "set": "BATTLEGROUNDS",
  "health": 30,
  "armor": 18,
  "heroPowerDbfId": 80229,
  "battlegroundsHero": true,
  "battlegroundsBuddyDbfId": 77876
}
```

**Key Fields**:
- `heroPowerDbfId`: Link to hero power (use with `bg_hero_powers.json`)
- `battlegroundsBuddyDbfId`: Link to buddy minion (search in `bg_minions.json`)
- `armor`: Starting armor (varies by hero balance)

### Hero Power (`bg_hero_powers.json`)

```json
{
  "id": "TB_BaconShop_HP_095",
  "dbfId": 80229,
  "name": "Forge a Warband",
  "type": "HERO_POWER",
  "cost": 1,
  "text": "[x]Give a minion +1/+2\nuntil next turn."
}
```

### Spell (`bg_spells.json`)

Includes spells available in Battlegrounds tavern or generated by cards.

## Shorthand Notation System

For compact text-based representation of minions and boards, see **[SHORTHAND.md](SHORTHAND.md)**.

**Format**: `T{tier}{tribes}{attack}/{health}[keywords]`

**Examples**:
- `T2B3/2` = Tier 2 Beast, 3/2 (Sewer Rat)
- `T6R12/12+T` = Tier 6 Dragon, 12/12 with Divine Shield and Taunt
- `T5M10/8+W` = Tier 5 Mech, 10/8 with Divine Shield and Windfury

**Usage**:
```bash
# Search for a minion
python3 shorthand.py search "Brann"

# List tier 6 minions
python3 shorthand.py tier 6

# Visualize example board
python3 shorthand.py board
```

See [SHORTHAND.md](SHORTHAND.md) for complete documentation.

## Usage Examples

### Load All Minions (Python)
```python
import json

with open('bg_minions.json') as f:
    minions = json.load(f)

# Get tier 1 minions
tier1 = [m for m in minions if m.get('techLevel') == 1]

# Get all Beasts
beasts = [m for m in minions if 'BEAST' in m.get('races', [])]
```

### Load All Minions (JavaScript/Node.js)
```javascript
const minions = require('./bg_minions.json');

// Get tier 1 minions
const tier1 = minions.filter(m => m.techLevel === 1);

// Get all Beasts
const beasts = minions.filter(m => 
  m.races && m.races.includes('BEAST')
);
```

### Query with `jq` (Command Line)
```bash
# Get all tier 1 Beasts
jq '[.[] | select(.techLevel == 1 and (.races | contains(["BEAST"])))]' bg_minions.json

# Get hero by name
jq '.[] | select(.name == "Rokara")' bg_heroes.json

# Count minions with Divine Shield
jq '[.[] | select(.referencedTags | contains(["DIVINE_SHIELD"]))] | length' bg_minions.json
```

## Relationships

### Hero → Hero Power
```bash
# Example: Get Rokara's hero power
HERO_POWER_ID=$(jq -r '.[] | select(.name == "Rokara") | .heroPowerDbfId' bg_heroes.json)
jq ".[] | select(.dbfId == $HERO_POWER_ID)" bg_hero_powers.json
```

### Minion → Golden Version
```bash
# Example: Get golden version of Sewer Rat
GOLDEN_ID=$(jq -r '.[] | select(.name == "Sewer Rat" and .battlegroundsPremiumDbfId != null) | .battlegroundsPremiumDbfId' bg_minions.json)
jq ".[] | select(.dbfId == $GOLDEN_ID)" bg_minions.json
```

## Update Strategy

To update this data when a new Hearthstone patch is released:

1. Check latest patch version:
   ```bash
   curl -s https://api.hearthstonejson.com/v1/ | grep -oE '[0-9]{6}'
   ```

2. Download new data:
   ```bash
   PATCH_VERSION=<new_version>
   curl -s "https://api.hearthstonejson.com/v1/$PATCH_VERSION/enUS/cards.json" | \
     jq '[.[] | select(.isBattlegroundsPoolMinion == true)]' > bg_minions.json
   ```

3. Repeat for heroes, hero powers, and spells

## Notes

### Rotation Status
This data includes **all minions that have existed** in Battlegrounds, but **not all are currently in the rotation**. Blizzard periodically rotates minions in/out of the pool for balance.

To track current rotation:
- Use external sources like Hearthstone Wiki, HSReplay, or official patch notes
- Implement manual curation of active minion pool

### Golden Cards
Golden (premium) cards have separate entries with doubled stats. Use `battlegroundsPremiumDbfId` to link normal → golden, or `battlegroundsNormalDbfId` to link golden → normal.

### Multi-Tribe Minions
Some minions have multiple tribes (e.g., `["BEAST", "DEMON"]`). Check the `races` array, not just the `race` field.
